As telas do sistema estão organizadas pelos perfis de atuação. O login de demonstração permite navegar entre cada um dos papéis (Fornecedor, Compras, Armazém e Administrador).

| Perfil | Tela | Estado |
| --- | --- | --- |
| **Fornecedor** | Meus Agendamentos | Pronta, integrada |
| **Fornecedor** | Agendar Entrega | Pronta, integrada |
| **Fornecedor** | Agendar na Hora | Pronta, integrada |
| **Fornecedor** | Previsão de Chuva | Pronta, consulta à Open-Meteo |
| **Fornecedor** | Dúvidas & Suporte Balança | Pronta |
| **Todos** | Login de demonstração por perfil | Pronta, integrada |
| **Compras** | Fila de Validação | Pronta / Em construção |
| **Compras** | Histórico de Validações | Pronta, integrada |
| **Armazém** | Recebimento (Agenda do dia) | Pronta, integrada |
| **Armazém** | Boletim Agrometeorológico | Pronta, integrada |
| **Armazém** | Boletim de Produção | Pronta, integrada |
| **Armazém** | Painel Gerencial | Pronta, integrada |
| **Administrador** | Documentação Geral (`/documentacao`) | Pronta, integrada |

A rota `/documentacao`, descrita em detalhes neste módulo, é restrita exclusivamente ao Administrador no menu e por redirecionamento de rota.
