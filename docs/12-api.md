# Referência da API REST

Esta seção documenta os endpoints disponíveis na API do backend do Recebimento Inteligente Cocapec.

> **Nota:** Os dados da especificação técnica detalhada abaixo são carregados a partir do arquivo `docs/fontes/openapi.json`, gerado estaticamente a partir da API FastAPI, permitindo consulta de parâmetros, schemas e payloads sem necessidade de chamadas externas em tempo de execução.
